# Iute 🌶 Site

Локальная визитка, которая работает прямо на этом ПК без сервера.

## Как открыть

Откройте файл `index.html` в браузере.

Чтобы показать кнопку админки владельцу, откройте:

```text
index.html?owner=1
```

## Админ панель

Файл: `admin.html`

Стандартный пароль:

```text
iute2026
```

В админке можно:

- добавлять, редактировать и удалять карточки с фото;
- добавлять отдельные кнопки чатов без фото;
- одобрять, скрывать и удалять отзывы;
- включать, отключать и менять новостное окно;
- сменить пароль.

Данные хранятся в браузере в `localStorage`, поэтому это локальный вариант для одного ПК.
